# Studio CLI Releases

Release artifacts for [Studio CLI](https://tokens.studio) — design tokens management for the command line.

## Installation

```bash
# npm (recommended)
npm install -g @tokens-studio/studio-cli

# or use directly
npx @tokens-studio/studio-cli

# Homebrew (macOS/Linux)
brew install tokens-studio/studio-cli/studio

# Shell script (macOS/Linux)
curl -fsSL https://tokens.studio/install.sh | sh
```
